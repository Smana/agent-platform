# Maku brand assets

Mark: "Orbit hex" — a split hexagon (the bounded stage) with a violet core (the run), inside a broken orbit ring with a satellite dot at the opening.

## Palette
| Token   | Hex     | Use |
|---------|---------|-----|
| Ink     | #0A0A0F | primary dark background |
| Surface | #14141C | cards / panels on Ink |
| Paper   | #F3F2FA | light background; mark on dark |
| Core    | #8B5CF6 | accent (rhombus, satellite, links, CTAs) |
| Muted   | #9B9AAE | secondary text on Ink |

## Type
Wordmark: Space Grotesk 700, lowercase "maku", tracking −3%. Body: Space Grotesk 500 or system sans.

## Files
- svg/ — source marks (transparent dark/light, mono white/black, rounded app icon)
- png/ — marks at 256/512/1024, lockups (horizontal + stacked, dark/light, @2x, transparent)
- favicon/ — favicon.svg, favicon-16/32/48, apple-touch-icon (180), icon-192/512 (PWA / manifest)
- social/ — GitHub social preview 1280×640 (URL reads `github.com/Smana/maku`; see social/README.md)

## Rules
- Clearspace around the mark: half the mark's width on every side.
- Use the "dark" mark on Ink/Surface, the "light" mark on Paper/white. Never recolor the core except in mono contexts.
- Do not rotate the mark; the orbit gap always sits top-right.
- Below 24 px use favicon/ versions (heavier strokes), not the regular mark.
